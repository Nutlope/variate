variate

Four real versions of one file, on the localhost you are already looking at. Your agent writes them. Arrow keys flip them. The one you keep is the code.

GitHub Install

Ask. Flip. Keep.

That is the whole loop.

  1. 01

    Ask

    /variate four takes on the hero

    Four real versions of that one file. Your stack, your tokens, your words. Nothing new gets installed.

  2. 02

    Flip

    ←→ and the page really changes. Each one has a name and tells you what it costs, so you read the tradeoff exactly where you decide.

  3. 03

    Steer

    Say calmer. Or mix them: 2's layout with 3's palette. Each part comes whole from one version, never averaged into mush.

    What you turn down is remembered. Dead ideas stay dead.

  4. 04

    Keep

    enter and that version is your file. The others are gone. git diff shows the design you chose and nothing else.

  5. 05

    Point

    Click any part of your page to start the next round there. The page is only ever measured, never touched.

The flip writes your real file.

So none of this exists:

  • preview server
  • iframe
  • wrapper component
  • build step
  • hydration risk
  • apply step

A version is just a .tsx, a .vue, a .css. Yours sits at position 1 and is never edited. Edit the live file by hand and that gets kept too.

Two commands.

Then ask for four takes.

# every agent on this machine, in one go git clone https://github.com/Luffixos/variate ~/code/variate node ~/code/variate/scripts/install.mjs
# optional, Claude Code: a card click reaches your agent while it sits idle node ~/code/variate/scripts/install.mjs --hooks

One install covers Claude Code, Codex CLI and opencode, and git pull updates all three. Anything else that runs a shell command works too: point it at AGENTS.md.
